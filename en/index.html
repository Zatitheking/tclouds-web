New direction · 2026

Game development

In 2026 we started our own game development branch. The first project is a turn-based strategy game for PC, with a console release planned further out.

In development

The same engineering approach as in our business software: the game's logic core is built as an engine-independent, independently testable library, with rendering layered on top. Development happens on PC; target platforms are tested on real console hardware.

  • GenreTurn-based strategy — city building, population, economy, army management.
  • TechnologyUnity and C#, with an engine-independent simulation core and automated tests.
  • PlatformPC first, console in a later phase of development.
  • StatusPrototype phase. No release date announced.
